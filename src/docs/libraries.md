# Libraries

A library is a reusable set of shapes — icons, diagram pieces, UI mockups —
that you can drop onto any canvas. Drawy uses Excalidraw's library format.

## Browse the catalog

Select **Libraries** in the sidebar. The browser loads the public catalog from
[libraries.excalidraw.com](https://libraries.excalidraw.com). Search by name,
open a library to preview its items, and choose **Save** to keep it.

## Saved libraries

Saving a library downloads its items into your personal library, which the
Excalidraw editor shows on every canvas. Manage saved libraries from the same
browser:

- **Refresh** re-downloads the items if the upstream library changed.
- **Browse** reopens that library's items.
- **Remove** deletes the saved copy. Items already added to your library stay in
  the editor until you remove them there.

Saved libraries and items live in your browser's local storage. They are not
tied to your account and do not sync to another browser or device.

## Add items from the canvas

Select shapes in the editor, then add them from Excalidraw's library panel.
Drawy persists the library as it changes, so your items are still there the next
time you open a canvas.

## Import from excalidraw.com

"Add to library" links on excalidraw.com point at Drawy. When such a link opens,
Drawy fetches the library and adds its items to your library. Only links hosted
on excalidraw.com or its subdomains are accepted.
