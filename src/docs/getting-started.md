# Getting started with Drawy

Drawy is a collaborative drawing workspace built on Excalidraw. Make an account,
start drawing, and invite someone when you want company.

## Create an account

An account is a username and a password — no email address, no confirmation
link, and no password reset email. Keep your credentials somewhere safe.

1. Open the [login page](/login).
2. Choose a username and a password.
3. Submit the form. You are signed in immediately.

Usernames can contain letters, numbers, underscores, and hyphens.

## Make a canvas

Select **New canvas** at the top of the sidebar. Your canvases appear below it,
grouped by when you last edited them.

Drawy saves as you draw: after a short pause the header shows **Saved**. The
**Save** button in the editor header forces a save if you do not want to wait.
Every canvas you own, or that someone shared with you, appears in the sidebar.

## Rename a canvas

Select the canvas title at the top of the editor, type a new name, and confirm.
Collaborators can rename a canvas too.

## Delete a canvas

Use the delete action on the canvas in the sidebar. Only the owner can delete a
canvas, and deleting it also removes its saved history and uploaded assets.

## Invite someone

Open **Share canvas** to publish a read-only link or give another Drawy user
edit access. Both are covered in [Sharing and collaboration](/docs/sharing).

## Export your work

Open the main menu in the canvas and choose **Export File (.excalidraw)**. The
file opens in any Excalidraw-compatible tool.
