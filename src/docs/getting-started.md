Drawy is a collaborative drawing workspace built on Excalidraw. Make an account,
start drawing, and invite someone when you want company.

## Create an account

An account is a username and a password. There is no email address, no
confirmation link and no password reset email, so keep your credentials
somewhere safe.

1. Open the [login page](/login).
2. Pick a username and a password.
3. Submit the form. You are signed in straight away.

Usernames may contain letters, numbers, underscores and hyphens. They are
lowercased, so `Ada` and `ada` are the same account.

## Make a canvas

Select **New canvas** at the top of the sidebar. Your canvases are listed below
it, grouped by when you last edited them.

Drawy saves as you draw. After a short pause the header shows **Saved**; the
**Save** button in the editor header forces a save straight away. Every canvas
you own, and every canvas someone shared with you, appears in the sidebar.

## Rename a canvas

Select the canvas title at the top of the editor, type a new name and confirm.
Collaborators can rename a canvas too, and everyone sees the new title.

## Delete a canvas

Use the delete action on the canvas in the sidebar. Only the owner can delete a
canvas, and deleting it also removes its saved history.

## Invite someone

Open **Share canvas** to publish a read-only link or give another Drawy user
edit access. Both are covered in
[Sharing and collaboration](/docs/sharing).

## Export your work

The menu in the canvas header exports the current canvas in three formats:

| Format        | Use it for                              |
| ------------- | --------------------------------------- |
| `.excalidraw` | Reopening the canvas in Excalidraw      |
| PNG           | Slides, issues and anything rasterised  |
| SVG           | Vector artwork that scales without blur |

The same menu imports a `.excalidraw` file back into the canvas, so a drawing can
move between Drawy and the Excalidraw app in either direction.
